# Diagnosis Quality Checklist

## Intake Quality (Phase 1)
- [ ] Setor classificado corretamente
- [ ] Porte da empresa identificado
- [ ] Maturidade tech avaliada
- [ ] Minimo 5 processos coletados (3 em quick-scan)
- [ ] Ferramentas atuais registradas
- [ ] Nenhum campo obrigatorio vazio

## Extraction Quality (Phase 2)
- [ ] Todos processos com classificacao (ouro/prata/bronze)
- [ ] Pareto ao Cubo aplicado (4 zonas)
- [ ] Gargalos identificados com tipo
- [ ] Nenhum processo generico/vago
- [ ] Processos especificos ao negocio (nao template)

## Scoring Quality (Phase 3)
- [ ] 4 dimensoes scoring pra cada oportunidade
- [ ] Criterios documentados (nao gut feeling)
- [ ] Diagnostic framework aplicado (6 perguntas)
- [ ] Automation decision por oportunidade
- [ ] Guardrails definidos pra cada automacao

## Ranking Quality (Phase 4)
- [ ] 10 oportunidades rankeadas
- [ ] ROI em range conservador (nao inflado)
- [ ] Loss Aversion aplicado (perda 2.5x)
- [ ] Conversion elements preparados
- [ ] Dopamine sequence definida

## Report Quality (Phase 5)
- [ ] ROI total no topo (ancora)
- [ ] Top 10 table completa
- [ ] Top 3 deep dive (teaser only)
- [ ] Loss aversion section
- [ ] CTA pra consultoria
- [ ] ZERO detalhes de implementacao (barreira)
- [ ] Formatacao profissional

## Strategic Barrier
- [ ] Report mostra O QUE, nunca O COMO
- [ ] ROI em range, nunca preciso
- [ ] Complexidade indicada, nunca cronograma
- [ ] CTA natural, nao forcado
